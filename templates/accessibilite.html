Déclaration d'accessibilité

L'application a été conçue pour être utilisable au clavier et avec les technologies d'assistance.

Mesures mises en place

  • structure HTML sémantique ;
  • libellé explicite pour chaque champ ;
  • ordre de tabulation logique ;
  • lien d'évitement vers le contenu principal ;
  • messages d'erreur annoncés avec le rôle d'alerte ;
  • contrastes renforcés ;
  • aucune information transmise uniquement par la couleur ;
  • mise en page responsive et zoomable.
